# Sonic Media Hub

## Descripción del Proyecto

Sonic Media Hub es una aplicación móvil desarrollada en Android Studio enfocada en la organización y exploración interactiva de contenido multimedia relacionado con la franquicia Sonic the Hedgehog.

La aplicación permitirá a los usuarios acceder a información sobre videojuegos, películas, personajes, series y cronologías desde una sola plataforma móvil.

---

## Exposición del Problema

Actualmente, la información relacionada con la franquicia Sonic the Hedgehog se encuentra distribuida entre múltiples plataformas digitales, dificultando el acceso organizado al contenido multimedia.

Sonic Media Hub busca centralizar dicha información mediante una interfaz intuitiva y moderna.

---

## Plataforma

La aplicación será desarrollada para dispositivos Android utilizando:

- Android Studio
- Kotlin
- Firebase Authentication
- Firebase Firestore
- Material Design

---

## Interfaz de Usuario

La aplicación contará con las siguientes pantallas:

- Pantalla de inicio
- Login y registro
- Explorador de personajes
- Timeline cronológico
- Favoritos
- Buscador multimedia

---

## Interfaz de Administrador

El administrador podrá:

- Agregar contenido
- Editar personajes
- Actualizar cronologías
- Gestionar imágenes y multimedia
